Seed Cards Feature new

Games that benefit from a prompt bank store a seed_cards array (and optional seed_label string) inside their definition JSONB. When game.js detects this field, it switches the game page into seed card mode.

Seed mode UI (game.html)

  • Normal Next Game and Feedback buttons are hidden.
  • A large yellow card displays a random prompt drawn from seed_cards.
  • New Card — animates a horizontal flip, draws the next prompt (avoids repeats until the deck cycles).
  • End Game — navigates to end.html for rating and scoring.
  • Skip button remains unchanged (marks event as skipped, returns to wheel).

Extensible: any game can gain a seed card bank by adding "seed_cards": [...] to its definition JSON — no code changes needed.

wheel.js — SVG Wheel

ConstantValueNotes
MAX_WEDGES7Maximum wedges displayed at once (not the total number of games).
WHEEL_RADIUS130SVG units. Outer rim of each wedge.
TEXT_RADIUS90SVG units. Radial position of emoji/label text.
CENTER_X / CENTER_Y150 / 150Center of 300×300 viewBox.

buildWheel(games, svgEl) — calls _selectDisplayGames to pick up to 7 games (one per category guaranteed, rest random), shuffled so same-category wedges are interleaved. Renders: wedge paths (category color, shade cycling), emoji text labels (flipped if in bottom half), center cap circle, fixed pointer polygon (id=wheel-pointer, outside #wheel-group so it stays above the spinning layer). Stores display list on svgEl._games.

spinTo(gameId, currentRotation, svgEl, onComplete) — looks up game UUID in svgEl._games. If not on wheel, calls onComplete immediately. Otherwise calculates final rotation (target wedge at 12-o'clock) + 8×360° of spin. Fires onComplete(finalRotation) on transitionend.

game.js — Game Page

Reads session.currentGame on load. Renders category badge, title, meta (duration/players/energy), numbered instruction steps, variants section.

Seed card mode: if def.seed_cards is a non-empty array, hides #mainActions, shows #seedSection. Sets label from def.seed_label. drawCard(animate) picks a random unused index; with animate=true plays a scaleX flip animation and swaps text at the midpoint. New Card button calls drawCard(true); End Game navigates to end.html.

end.js — Feedback + Scoring

Reads session.currentGame. Shows offline warning if playEventId is null.

Player grid: initial checked state from localStorage('moment_last_players'), falling back to session.players. Checking/unchecking a player immediately rebuilds the winner grid.

Save guard: notes typed with no rating selected → inline warning + scroll to rating row. Button re-enabled on any cloud failure so the user can retry.

_submit() flow: save player selection to localStorage → updatePlayEvent → submitFeedback (if rated) → saveScore (if winner) → updateScores + recordPlayEvent + clearCurrentGame (always, even on cloud failure). Returns { ok, navigateAnyway, errors }.
